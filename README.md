# Myntra Clone

This project is a simple **Myntra Clone** built with **HTML**, **CSS**, and **JavaScript**. It mimics the layout and basic functionality of the popular online fashion and lifestyle store, Myntra. The project features a responsive design with a product listing page, product details page, and a basic shopping cart.

## Features

- **Responsive Design**: The website adjusts beautifully to various screen sizes (mobile, tablet, and desktop).
- **Product Listing**: Products are displayed in a grid layout.
- **Product Details**: Shows details like price, description, and an image of the selected product.
- **Shopping Cart**: Basic functionality to add items to the cart (static).
- **Search Functionality**: A search bar to filter products by name.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Responsive Design**: Media queries for mobile-first design
- **No Backend**: Static data (no database integration)

## Installation

To run the project locally:

1. Clone the repository:
    ```bash
    git clone https://github.com/sayali9604/Myntraclone.git
    ```

2. Navigate into the project folder:
    ```bash
    cd Myntraclone
    ```

3. Open the `index.html` file in your browser to view the website.

There are no external dependencies required for this project as it uses plain HTML, CSS, and JavaScript.
